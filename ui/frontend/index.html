Help & Information


            

                
What is SatisFacts?

                
SatisFacts is a desktop tool for inspecting and editing Satisfactory save files (.sav). It can analyze saves, optimize file size, reorder the Dimensional Depot, upgrade belts/lifts/pipes, copy blueprint categories between saves, modify game multipliers beyond UI limits, and fix session name issues — all without modifying the original file (unless you explicitly choose to overwrite).

            


            

                
Getting Started

                
    
                    
  1. Select a save file — Go to the Home tab and click Browse to pick any .sav file, or click Satisfactory Saves to open your default save directory. You can also drag and drop a .sav file anywhere onto the window.
    2. 
                    
  2. View save info — Once loaded, the file name, size, session name, and save version are displayed on the Home page.
    3. 
                    
  3. Run a feature — Navigate to any tab (Analyze, Optimize, Depot, Belts, Blueprints, Multipliers) and follow the instructions on that page.
    4. 
                    
  4. Choose output location — Each feature lets you save the result next to the app, next to the original save, or in a custom folder. The tool never overwrites your original unless explicitly stated.
    5. 
                    
  5. Chain operations — After running one operation, the next operation can optionally chain onto the previous output file instead of starting from the original.
    6. 
                

            


            

                
How It Works

                
Satisfactory save files are compressed binary archives containing a header (metadata) and body (game objects). SatisFacts:

                
    
                    
  1. Parses the save file — decompresses zlib chunks, reads the header, and parses object data.
    2. 
                    
  2. Modifies the in-memory representation — reordering, patching values, replacing class names, etc.
    3. 
                    
  3. Re-serializes — writes the modified data back, recompressing with zlib.
    4. 
                    
  4. Writes a new .sav file with the appropriate suffix (_optimized, _reordered, _upgraded, _multipliers, _blueprints, _sessionfix).
    5. 
                

                
The original save file is never modified unless you explicitly choose Overwrite original save (only available for session name fix).

            


            

                
Safety & Backups

                
    
                    
  • All operations create a new file by default — your original save is untouched.
    • 
                    
  • Each output file is named with a suffix (e.g. Save1.2_optimized.sav) so you can identify what was done.
    • 
                    
  • The chaining feature lets you apply multiple operations in sequence without manually renaming files.
    • 
                    
  • If a save file is corrupt or unparseable, all operation buttons are disabled and a red error banner appears.
    • 
                    
  • Always keep backups of your saves before applying edits, just in case.
    • 
                

            


            

                
Tips

                
    
                    
  • Drag & drop — Drop any .sav file onto the window to load it instantly.
    • 
                    
  • Auto-detect — Enable in Settings to automatically load the newest save from your Satisfactory save directory whenever it changes. It waits until a save has finished writing and ignores files this app creates.
    • 
                    
  • Auto-analyze — When auto-detect is on, you can also auto-generate a report each time a new save is detected.
    • 
                    
  • Output location — Set a default in Settings, or override per-operation using the radio toggles on each page.
    • 
                    
  • Recent saves — Recently loaded saves appear on the Home page and in Settings for quick access.
    • 
                    
  • Language, zoom and updates — Switch language and zoom in the top right. Check for new versions on the Settings page.
    • 
                

            


            

                

                    
Features


                
Analyze

                
Generates a detailed HTML report from your save file. The report includes overview stats, buildings, power, manufacturing, storage, logistics, transport, collectibles, and more.

                
    
                    
  • The report has 14 tabs in order: overview (save info, colony summary, custom map settings), structures (foundations, walls, beams, lights, signs), buildings (every building categorized by function), clock speeds (overclock/underclock distributions, somersloop usage), power (generation, consumption, grid balance), extraction (miners and fluid extractors with resources and purities), manufacturing (recipe efficiency, bottlenecks), storage (container contents and fill levels), logistics (belts, pipes, splitters, mergers), transport (trains, vehicles, drones with route distances), nuclear (fuel, waste, production rates), collectibles (power slugs, somersloops, mercer spheres, crash sites), extras (space elevator, milestones, MAM research, AWESOME Sink, player stats), and map (interactive factory map with filters).
    • 
                

                
After generation, click Open Report to view it in your browser. Very large saves can produce big reports: if one won't open, use Firefox, or untick Include interactive map and generate it again.


                
Optimize

                
Typically reduces save file size by 10–23% by reorganizing how data is stored internally. Your factory, buildings, and all game objects remain exactly the same — only the file gets smaller. Large saves also load somewhat faster. The game loads optimized saves normally.


                
Depot Reorder

                
Drag and drop to reorder items in the Dimensional Depot, or use the auto-sort buttons (A–Z, Most Space, Least Space). The order in the save file determines the display order in-game. Load items, rearrange them, preview the changes, and save a new file.


                
Belt & Pipe Upgrade

                
Upgrade all conveyor belts, lifts, and pipelines to a higher Mk tier in one click. The tool scans your save for all belts/lifts/pipes, shows you the inventory by Mk level, and lets you choose a target tier. Everything is upgraded in-place — no structural changes to the save.

                
    
                    
  • HUB Tier detection — The tool detects which tiers you've unlocked and warns if you try to upgrade above them. Enable Allow upgrading above unlocked tiers to override.
    • 
                    
  • Pipelines — Only 2 tiers exist. Mk1 pipes can be upgraded to Mk2.
    • 
                    
  • Modded content — Belts, lifts, or pipes from mods (e.g. modded Mk3+ pipes) are detected and listed but cannot be upgraded. They are left untouched in the output save.
    • 
                


                
Blueprint Categories

                
Copy your blueprint category folders (the organizational structure in Build Menu → Blueprints tab) from one save to another, or export them as a portable .sfbcat preset file that can be imported into any other save. This copies the folder structure, not placed blueprint instances.

                
    
                    
  • Replace — Overwrite all target categories with source categories.
    • 
                    
  • Merge — Add source categories that don't exist in target, keeping existing ones. Duplicates are skipped (case-insensitive).
    • 
                    
  • Preset files (.sfbcat) — Export categories from a save to a portable preset file, then import them into any other save later. Share your folder structure with friends without sending the whole save.
    • 
                


                
Multipliers

                
Modify custom game multipliers beyond the in-game UI limits. The game reads these values directly from the save file with no caps, so you can set them as high or low as you want. Multipliers that were not set during world creation (shown as not set) can be added retroactively — the tool inserts the missing property into the save and the game honors it on load. Load current values, edit them, preview changes, and save.


                
Session Name Fix

                
Automatically detects session name issues (trailing/leading whitespace, trailing periods, invalid Windows folder characters) when a save is loaded. A warning card appears on the Home page with an auto-fix suggestion. You can edit the name manually, choose to overwrite the original or save a fixed copy, and the fixed save is automatically loaded into the tool afterward.


                
Game Config

                
Edit Satisfactory's configuration files (Engine.ini and Input.ini) without hunting for them manually. The tool auto-detects the config directory and lets you apply two common tweaks with a single click:

                
    
                    
  • UObject Limit — Increases the Unreal Engine object limit from 2,162,688 to 100,000,000. This prevents crashes on very large factories. A backup (Engine.ini.bak) is created before any change.
    • 
                    
  • Console Key — Binds a key (e.g. F6) to open the in-game debug console. Useful for non-QWERTY keyboards where the default §/~/` key is hard to reach. The file is set to read-only after applying (the game deletes contents otherwise). A backup (Input.ini.bak) is created.
    • 
                

                
Both tweaks can be reverted via the Restore from Backup button. The config directory can also be set manually via Browse if auto-detection fails.


                
Map Settings

                
Customize the colors used for each category in the map view of analysis reports. The map tab in the report shows your factory on a 2D top-down map with buildings, transport lines, power poles, resource nodes, and collectibles. Each category has a default color — use the Map Settings tab to change any of them to your preference.

                
    
                    
  • Color customization — 20 categories across 7 groups (Production, Power, Transport, Stations, Special, Build, Collectibles). Each has a color picker. Changes are saved automatically.
    • 
                    
  • How it works — Colors are embedded into each new analysis report you generate. Existing reports keep their original colors. Use Reset to Defaults to restore the default color scheme.
    • 
                    
  • Collectible markers — Collectibles (power slugs, somersloops, mercer spheres, crash sites) appear as arrow markers on the map. Once enabled, they stay visible at every zoom level. Their colors can be customized here too.
    • 
                

                

            


            

                

                    
FAQ

                

                    
Is this safe to use with my saves?

                    
Yes. The tool never modifies your original file (except session name fix with explicit overwrite). All operations produce a new file. Always test the output in-game before relying on it.

                

                

                    
Will the game detect modified saves?

                    
In testing, modified saves load normally. However, always make backups before extensive editing.

                

                

                    
Why is my optimized save smaller?

                    
Objects in the save are sorted by class name, which dramatically improves zlib compression. The data is identical — just ordered differently. No information is lost.

                

                

                    
Can I undo changes?

                    
There's no undo — but since the original file is preserved, you can always go back to it. Keep your original saves as backups.

                

                

                    
What save versions are supported?

                    
The tool supports Satisfactory save version 1.0 and later. Older saves may work but are not officially tested.

                

                

                    
The session name fix says my new name is too long — why?

                    
The fix uses a null-padding technique that requires the new name to be shorter than or equal to the original name's byte length. Try a shorter name.

                

                

                    
The session name fix rejects umlauts or special characters — why?

                    
If your current session name only uses plain characters, the save stores it in a format that can't hold umlauts or other special characters. Use plain letters, digits and symbols instead.

                

                

                    
Why is the "Custom" output option greyed out?

                    
The Custom output location lets you save files to a directory of your choice. To enable it, go to Settings and click Browse next to Custom output path. Once a folder is set, the Custom option becomes available on every tab.

                

                

                    
The app is slow or crashes on a very large save — what can I do?

                    
Save files of several hundred MB decompress to multiple GB in memory. Analysis and Optimize peak at roughly 30× the file size, so 16 GB of RAM generally works for saves up to ~450 MB. Close other applications before processing large saves, or use a machine with more RAM.

                

                

                    
Can I set multipliers higher than the in-game sliders allow?

                    
Yes. The in-game sliders have client-side limits, but the save file stores the raw values. SatisFacts can set them to any value — the game reads them directly with no caps. For example, you can set power consumption to 10x even though the in-game slider maxes out at 5x.

                

                

                    
A multiplier shows "not set" — what does that mean?

                    
This means the multiplier was never set — either because the option didn't exist when the world was created, or because no custom multipliers were configured at all. You can still set a value and SatisFacts will insert the missing multiplier into the save file. The game honors it on load. This has been tested with saves missing individual multipliers and saves with no custom multipliers at all — both work without issues.

                

                

                    
My game still crashes after increasing the UObject limit — why?

                    
Very large factories can still run into memory limits, and raising the UObject limit too high can cause memory instability. Check that the change is shown as applied on the Game Config page, and keep regular backups of your saves.

                

                

                    
Why is Input.ini set to read-only?

                    
Satisfactory (Unreal Engine 5) deletes the contents of Input.ini on launch if the file is writable. Setting it to read-only prevents the game from wiping your console key binding. If you need to edit the file manually, temporarily remove the read-only flag, make your changes, then set it back to read-only.

                

                

                    
My custom map colors don't show in an old report — why?

                    
Custom colors are embedded into each report at generation time. Reports you generated before changing colors keep their original color scheme. Generate a new report to see your updated colors.
